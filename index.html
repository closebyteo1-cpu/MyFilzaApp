CÀI ĐẶT TRỰC TIẾP TRÊN IPHONE TẢI FILE .IPA MIỄN PHÍ

Cách 1: Cài trực tiếp (OTA)

Bấm nút CÀI ĐẶT TRỰC TIẾP ➔ Mở Safari ➔ Bấm "Cài đặt" ở popup. Về Màn hình chính xem app tải về.

Cách 2: Cài bằng File .IPA (Nếu báo lỗi tính toàn vẹn)

Bấm TẢI FILE .IPA ➔ Dùng các ứng dụng như TrollStore, AltStore, SideStore hoặc ESign để nhập và cài đặt vĩnh viễn.
